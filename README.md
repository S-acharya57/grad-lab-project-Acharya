# Evaluating Event Camera Simulation for Downstream Vision Tasks

**Student:** Sajjan Acharya  
**Course:** Graduate Laboratory (Grad Lab)

## Project Overview

Event cameras are a type of imaging sensor that capture changes in brightness asynchronously rather than recording conventional image frames.

This project will investigate how accurately simulated event-camera data represent real event-camera measurements and how simulation quality affects downstream computer vision tasks.

The initial goal is to understand the characteristics of simulated event streams and explore their usefulness for event-based vision applications.

## Planned Data and Imaging Modality

- Event-based vision and event-camera data.
- Simulated event streams generated using v2e.
- Comparison with real event-camera recordings using similarity metrics.
