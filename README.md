## Project Overview

Event cameras are a type of imaging sensor that capture changes in brightness asynchronously rather than recording conventional image frames.

This project will investigate how accurately simulated event-camera data represent real event-camera measurements and how simulation quality affects downstream computer vision tasks.

The initial goal is to understand the characteristics of simulated event streams and explore their usefulness for event-based vision applications.

## Planned Data and Imaging Modality

- Event-based vision and event-camera data.
- Simulated event streams generated using v2e.
- Comparison with real event-camera recordings using similarity metrics.

## Reflection

### What is a commit?

A commit is a saved snapshot of changes in a Git repository. It records changes in codebase, with a message describing what was changed.

### Why might you use a branch instead of editing main directly?

A branch allows developers to work on new features independently without directly affecting the main version of the project. Once such features are added, they can be reviewed before being merged into main. This gives freedom to try out new things without affecting the main codebase.

### How does an issue differ from a pull request?

An issue is used to describe and track a task, bug, or improvement. However, a pull request proposes actual changes in the codebase and allows them to be reviewed before merging them into the other branch.
